# YARD ZERO

모바일용 3D FPS. 항만 일대(컨테이너 야드, 부두, 차량기지)에서 팀원과 함께 단계별 작전을 수행하거나, 생존 모드에서 웨이브를 막는 게임이다. 멀티플레이는 방 코드로 모여 같은 웨이브를 막거나(협동 생존), 임무를 함께 수행하거나(협동 임무), 서로 싸운다(대결 개인전·팀전).
three.js 0.170.0 번들, 병사 모델, 효과음, 애니메이션, 네트워크 라이브러리(PeerJS)를 모두 넣은 단일 HTML 파일로 동작한다.

- 최신 릴리스: `index.html` (현재 v0.9, 설치형 PWA)
- 버전별 스냅샷: `versions/yard-zero-v0.x.html`
- 변경 기록과 검증 내용: `CHANGELOG.md`

## 실행

GitHub Pages를 켜면 `https://aaronkyung-a11y.github.io/yard-zero/` 에서 열린다. 터치(가로 화면 권장)와 키보드·마우스를 모두 지원한다.

앱으로 설치:
- Android Chrome: 메뉴의 "앱으로 설치" 버튼 또는 브라우저 메뉴의 "앱 설치"
- iOS Safari: 공유 버튼 → "홈 화면에 추가"
- 다른 사람에게 보낼 때는 메뉴의 "친구에게 공유"를 누른다. 폰의 공유 창으로 이 주소와 설치 안내가 나간다

한 번 열면 서비스 워커가 캐시해 오프라인에서도 실행된다. 파일로 직접 열 때는 `versions/`의 스냅샷을 쓴다.
지금 실행 중인 버전은 메뉴 맨 위, 게임 중 점수 아래, 게임 중 메뉴에 표시된다. 열려 있는 화면보다 새 판이 받아지면 메뉴에 "새 버전 적용" 버튼이 나타난다.

## 멀티플레이 (네트워크)

- 한 명이 "멀티플레이 → 방 만들기"로 방을 열고 숫자 5자리 코드를 알려 주면, 나머지는 "코드로 참가"에서 그 코드를 넣는다. 최대 4명
- 방장이 로비에서 모드를 고른다
  - 협동 생존: 야드에서 같은 웨이브를 막는다. 쓰러지면 10초 뒤 복귀, 전원이 함께 쓰러지면 끝
  - 협동 임무(1~4명): 임무 3개. 폭파조(야드: 폭약 설치 → 지키기 → 이탈), 화물 회수(부두: 상자 2개 운반 → 사수), 구출(차량기지: 잠금 해제 → 조종사 부축 → 사수). 데이터는 `src/episodes.js`의 `MISSIONS`
  - 대결 (개인전): 방장이 고른 맵에서 서로 싸운다. 먼저 목표 킬(5·10·15·20)에 닿으면 승리. 쓰러지면 4초 뒤 상대와 떨어진 자리에서 복귀
  - 대결 (팀전): 청팀 대 홍팀. 각자 "내 팀" 버튼으로 팀을 바꾼다. 같은 팀끼리는 피해가 없고 팀의 킬을 더해 겨룬다
- 방장은 게임 중 메뉴(오른쪽 위 ☰)나 종료 화면의 "로비로"로 방을 유지한 채 모드를 바꿀 수 있다
- 서버를 따로 두지 않는다. 폰끼리 직접 연결(WebRTC 데이터 채널)하고, 처음 서로를 찾는 중개만 PeerJS 공개 서버(`0.peerjs.com`)를 쓴다
- 중계 서버는 없다(v0.8 기준). 두 폰이 직접 닿지 못하는 통신망 조합에서는 연결되지 않는다. 같은 와이파이에서 안 되면 한 폰의 와이파이를 끄고 모바일 데이터로 들어오면 된다. 실패하면 원인 안내와 진단 문자열이 로비에 나온다. 중계 서버를 붙이려면 `src/net.js`의 `RELAY`에 주소와 계정을 넣는다
- 방을 만든 폰(방장)이 협동 생존·협동 임무의 적 AI와 진행, 대결의 점수를 계산한다. 방장 폰의 화면이 꺼지거나 앱이 뒤로 가면 모두 멈춘다
- 모든 폰이 같은 버전이어야 한다. 버전이 다르면 입장할 때 안내가 나온다
- 전송 계층은 `src/net.js`, 게임 쪽 동기화는 `src/main.js`의 "네트워크 플레이" 부분

## 빌드

```
npm install
node build.mjs v0.x    # index.html(PWA) + sw.js, dist/index.html, versions/yard-zero-v0.x.html
```

## 구조

- `src/` 게임 코드 (`main.js` 게임 루프·무기·적과 팀원 AI·작전 진행·네트워크 동기화(협동 생존·대결), `net.js` 네트워크 전송 계층, `episodes.js` 작전과 분대 데이터, `world.js` 맵 3종·충돌·내비게이션, `mocap.js`·`retarget.js` 병사 애니메이션, `audio.js` 효과음, `viewmodel.js` 1인칭 총기, `textures.js` 절차적 텍스처)
- `assets/` 병사 모델, 애니메이션 클립, 효과음 샘플
- `pwa/` PWA 머리말 태그와 서비스 워커 원본, `manifest.webmanifest`, `icons/`
- `tools/` 에셋 가공 스크립트 (모델 경량화, 클립 추출, 효과음 자르기)
- `test/` 헤드리스 Chrome 테스트 스크립트 (Playwright 경로는 작업 환경 기준)
